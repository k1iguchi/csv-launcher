# CSV Launcher 詳細仕様書

本書は CSV Launcher を新規実装するための実装仕様を定義する。
要件定義書が定義する要求に対して、実装レベルの設計・処理・データを規定する。

## 1. 実装構成

### 1.1 モジュール
- Program
  - エントリーポイント
  - キャンセルハンドリング（Ctrl+C）
  - 終了コード変換
  - 実行オーケストレーション
  - ブラウザ起動
- AppOptionsParser
  - 引数解析
- GoogleAuthService
  - OAuth 認証
  - token.json 永続化
- DriveUploader
  - 重複検索
  - 重複ポリシー処理
  - Google スプレッドシート変換アップロード
  - 空スプレッドシート作成
- TextEncodingConverter
  - 文字コード判定
  - UTF-8 ストリーム変換
- EmbeddedGoogleOAuth
  - ClientId/ClientSecret 定数定義
- scripts/setup.ps1
  - .csv 関連付け登録/解除
- scripts/embed-oauth.ps1
  - credentials.json から EmbeddedGoogleOAuth.cs を生成

### 1.2 依存パッケージ
- Google.Apis.Auth 1.75.0
- Google.Apis.Drive.v3 1.75.0.4210
- Ude.NetStandard 1.2.0

## 2. 実行フロー

1. Main で Encoding.RegisterProvider(CodePagesEncodingProvider.Instance) を呼び出す。
2. Main で CancellationTokenSource を作成し、Console.CancelKeyPress でキャンセル伝播を設定する。
3. RunAsync で AppOptionsParser.Parse により引数を解析する。
4. --help/-h/? 指定時は usage を出力して return 0。
5. GoogleAuthService.GetCredentialAsync を実行。
6. DriveUploader を生成する。
7. CSV パス指定ありの場合
  - パスをフルパス化し、存在確認。
  - DriveUploader.UploadCsvAsSpreadsheetAsync を実行。
8. CSV パス指定なしの場合
  - DriveUploader.CreateEmptySpreadsheetAsync を実行（空スプレッドシート作成）。
9. 返却 fileId で URL を組み立て、UseShellExecute=true で既定ブラウザ起動。
10. 正常時 return 0。
11. OperationCanceledException（ユーザーキャンセル）時は "[INFO] キャンセルされました。" を stderr 出力して return 130。
12. その他例外時は "[ERROR] <message>" を stderr 出力して return 1。
13. finally で Console.CancelKeyPress のハンドラを解除する。

## 3. コマンドライン詳細

### 3.1 形式

```text
CsvLauncher.exe [--folder-id=<drive-folder-id>] [<csv-path>]
```

### 3.2 引数解析仕様
- サポート引数
  - --help, -h, /?
  - --folder-id=<id>
- 未知の -- 引数は ArgumentException。
- CSV パス未指定時は空スプレッドシート作成モードで実行する。
- CSV パスは 1 個のみ許可。2 個目は ArgumentException。

## 4. 認証仕様

### 4.1 スコープ
- DriveService.Scope.DriveFile

### 4.2 OAuth 情報
- EmbeddedGoogleOAuth.ClientId
- EmbeddedGoogleOAuth.ClientSecret
- いずれか空白時は InvalidOperationException
  - メッセージ: OAuth client settings are not embedded in this build artifact.

### 4.3 トークン保存
- ディレクトリ: %APPDATA%/csv-launcher
- ファイル: %APPDATA%/csv-launcher/token.json
- IDataStore 実装: SingleFileTokenStore
  - C# 12 プライマリコンストラクタで tokenPath を受け取る。
  - StoreAsync: System.Text.Json（WriteIndented=true）で JSON 保存
  - GetAsync: JSON 読み出し。デシリアライズ結果が null の場合は InvalidDataException
  - DeleteAsync: token ファイル削除
  - ClearAsync: token ファイル削除

### 4.4 認証処理
- GoogleWebAuthorizationBroker.AuthorizeAsync を使用。
- user キーで資格情報を取得。

## 5. Drive 連携仕様

### 5.1 ファイル名
- spreadsheetName = Path.GetFileNameWithoutExtension(csvPath)

### 5.1A 空スプレッドシート名
- 引数なし起動時は次の形式で名前を生成する。
  - New Spreadsheet yyyyMMdd-HHmmss

### 5.2 既存ファイル検索
同名ファイル存在時でも既存ファイルは保持し、新規スプレッドシートを作成する。

### 5.5 CSV バイト列処理
- TextEncodingConverter.OpenUtf8StreamAsync を使用する。
- 先頭 64KB をプローブ読み取りし DetectEncoding で文字コード推定。
- 入力は FileStream（bufferSize=81920, 非同期）で開く。
- StreamReader で読み、StreamWriter（UTF-8/BOMなし, bufferSize=81920）で MemoryStream に段階変換する。
- 変換後の MemoryStream は Position=0 に戻して返す。

### 5.6 DetectEncoding アルゴリズム
1. BOM 判定
   - EF BB BF -> UTF8Encoding(false)
   - FF FE -> Encoding.Unicode
   - FE FF -> Encoding.BigEndianUnicode
2. Ude CharsetDetector 実行
3. detector.Charset が得られた場合
   - Encoding.GetEncoding(detector.Charset) を試行
   - 失敗時はフォールバックへ
4. フォールバック
   - Encoding.GetEncoding("shift_jis")

### 5.7 CSV 変換アップロード API 呼び出し
- metadata:
  - Name = spreadsheetName
  - MimeType = application/vnd.google-apps.spreadsheet
  - Parents = [folderId]（folderId 指定時のみ）
- Files.Create(metadata, csvStream, "text/csv")
- create.Fields = "id"
- UploadAsync 実行

### 5.7A 空スプレッドシート作成 API 呼び出し
- metadata:
  - Name = 生成名（または指定名）
  - MimeType = application/vnd.google-apps.spreadsheet
  - Parents = [folderId]（folderId 指定時のみ）
- Files.Create(metadata)
- create.Fields = "id"
- ExecuteAsync 実行

### 5.8 成功判定とエラー条件
- uploadResult.Status == Completed であること。
- create.ResponseBody.Id が null でないこと。
- 失敗時は InvalidOperationException。

空スプレッドシート作成時:
- ExecuteAsync の戻り値 Id が null でないこと。
- null の場合は InvalidOperationException。

## 6. ブラウザ起動仕様

- URL: https://docs.google.com/spreadsheets/d/{fileId}/edit
- ProcessStartInfo
  - FileName = URL
  - UseShellExecute = true

## 7. 例外と終了コード

- 例外は Main の catch で一括処理。
- 出力先: Console.Error
- フォーマット:
  - キャンセル時: [INFO] キャンセルされました。
  - それ以外: [ERROR] <message>
- 終了コード:
  - 正常: 0
  - キャンセル: 130
  - 異常: 1

実装方針:
- API リトライ処理は実装していない。
- スタックトレース出力はしない。

## 8. ビルドと配布仕様

### 8.1 scripts/build.ps1 手順
1. embed-oauth.ps1 を呼び出し OAuth 定数を再生成。
2. dotnet publish 実行。
3. scripts/setup.ps1 と LICENSE と THIRD_PARTY_NOTICES.md を dist へコピー。
4. dist/credentials.json があれば削除。
5. dist/CsvLauncher-<Version>.zip を作成。

### 8.2 publish パラメータ

```text
dotnet publish CsvLauncher\CsvLauncher.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o .\dist
```

### 8.3 成果物
- dist/CsvLauncher.exe
- dist/setup.ps1
- dist/CsvLauncher-<Version>.zip
- dist/LICENSE
- dist/THIRD_PARTY_NOTICES.md

### 8.4 事前準備（Google OAuth クライアント作成）

1. Google Cloud Console でプロジェクトを作成または選択する。
2. API とサービスからライブラリを開き、Google Drive API を有効化する。
3. API とサービスから認証情報を開き、認証情報を作成を選ぶ。
4. OAuth クライアント ID を選び、アプリケーションの種類はデスクトップアプリを選択する。
5. 作成後に JSON をダウンロードする。

補足:
- ダウンロード直後のファイル名は client_secret_xxx.json になることがある。
- スクリプトは installed セクションと web セクションの両方に対応する。

### 8.5 credentials.json の配置ルール

ビルド時に scripts/embed-oauth.ps1 は、リポジトリルートの credentials.json のみを探索する。

重要:
- ルートに credential.json という名前のファイルがあっても検出対象外。必ず credentials.json という名前を使う。

### 8.6 ローカルビルド手順（実装者向け）

1. リポジトリルートに移動する。
2. credentials.json を配置する。
3. scripts/build.ps1 を実行する。
4. dist 配下に成果物が生成されることを確認する。

PowerShell 実行例:

```powershell
Set-Location C:\work\csv-launcher
.\scripts\build.ps1
```

### 8.7 ビルド成功判定

- コンソールに Build completed: dist\CsvLauncher.exe が表示される。
- dist/CsvLauncher.exe が存在する。
- dist/setup.ps1 が存在する。

補足:
- ビルド時トラブルシュートは [docs/ビルド手順書.md](docs/ビルド手順書.md) を正とする。

## 9. OAuth 埋め込みスクリプト仕様

### 9.1 探索対象
1. <root>/credentials.json

### 9.2 JSON 解釈
- installed 優先、なければ web を使用。
- client_id/client_secret 必須。

### 9.3 出力
- CsvLauncher/EmbeddedGoogleOAuth.cs を UTF-8 で上書き。
- C# 文字列用にバックスラッシュとダブルクォートをエスケープ。

## 10. 関連付けスクリプト仕様

### 10.1 scripts/setup.ps1 引数
- -ExePath
- -FolderId
- -Uninstall

### 10.2 レジストリ書き込み（登録時）
- HKCU/Software/Classes/.csv (default) = CsvLauncher.csv
- HKCU/Software/Classes/CsvLauncher.csv (default) = CSV Launcher
- HKCU/Software/Classes/CsvLauncher.csv/shell/open/command (default) =
  "<resolved exe path>" [--folder-id=<id>] "%1"

### 10.3 登録解除
- .csv の default が CsvLauncher.csv のときのみ削除。
- HKCU/Software/Classes/CsvLauncher.csv を再帰削除。

## 11. 設計上の注意点

- 同名ファイル存在時でも既存ファイルは保持され、新規スプレッドシートが作成される。
- scripts/setup.ps1 の管理者判定関数は実処理では未使用。
