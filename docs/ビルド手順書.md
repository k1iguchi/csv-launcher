# CSV Launcher ビルド手順書

## 1. この文書の目的

この文書は、Google OAuth クライアント設定ファイルの作成とダウンロードから、CsvLauncher.exe のビルド完了までを単独で実施できるようにするための手順書です。

## 2. 事前準備

- OS: Windows 10/11
- .NET SDK: 8 系
- Google アカウント
- インターネット接続

## 3. OAuth 設定ファイルの作成

### 3.1 Google Cloud プロジェクト作成

1. Google Cloud Console を開く。
2. 新規プロジェクトを作成する。

## 3.2 Google Drive API を有効化

1. API とサービス画面を開く。
2. ライブラリで Google Drive API を検索する。
3. Google Drive API を有効化する。

## 3.3 OAuth 同意画面の設定

1. API とサービスの OAuth 同意画面を開く。
2. 外部または内部を選択し、必要項目を入力して保存する。
3. テストユーザー運用の場合は、利用する Google アカウントを追加する。

## 3.4 OAuth クライアント ID の作成

1. API とサービスの認証情報を開く。
2. 認証情報を作成から OAuth クライアント ID を選ぶ。
3. アプリケーションの種類は デスクトップアプリ を選ぶ。
4. 作成後、JSON をダウンロードする。

## 4. 設定ファイルの配置

ビルド時スクリプトは、リポジトリ直下の credentials.json のみを参照します。

注意:
- ダウンロードしたファイル名が client_secret_xxx.json の場合は、credentials.json にリネームしてリポジトリ直下へ配置してください。

## 5. ビルド手順

### 5.1 コマンド

リポジトリ直下で次を実行します。

```powershell
.\scripts\build.ps1
```

### 5.2 scripts/build.ps1 が内部で行う処理

1. scripts/embed-oauth.ps1 を実行し、OAuth 情報を CsvLauncher/EmbeddedGoogleOAuth.cs に埋め込む。
2. dotnet publish で単一 EXE を生成する。
3. scripts/setup.ps1 と LICENSE と THIRD_PARTY_NOTICES.md を dist にコピーする。
4. dist/credentials.json があれば削除する。
5. dist/CsvLauncher-<Version>.zip を作成する。

publish 実行パラメータ:

```text
dotnet publish CsvLauncher\CsvLauncher.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o .\dist
```

## 6. ビルド成果物

ビルド成功時、次が生成されます。

- dist/CsvLauncher.exe
- dist/setup.ps1
- dist/CsvLauncher-<Version>.zip
- dist/LICENSE
- dist/THIRD_PARTY_NOTICES.md

## 7. 動作確認

1. dist/CsvLauncher.exe が存在することを確認する。
2. 必要に応じて dist/setup.ps1 で関連付けを登録する。
3. CSV を開いて、Google スプレッドシートがブラウザで開くことを確認する。

関連付け登録例:

```powershell
.\dist\setup.ps1
```

関連付け解除例:

```powershell
.\dist\setup.ps1 -Uninstall
```

## 8. よくある失敗と対処

### 8.1 credentials.json が見つからない

原因:
- リポジトリ直下に credentials.json が配置されていない。
- ファイル名が credentials.json ではない。

対処:
- リポジトリ直下に credentials.json を置いて再実行する。

### 8.2 client_id または client_secret が無い

原因:
- ダウンロードした JSON が OAuth クライアント情報ではない。

対処:
- OAuth クライアント ID を デスクトップアプリ で再作成し、JSON を再ダウンロードする。

### 8.3 dotnet publish で失敗する

原因:
- .NET SDK 8 未インストール、または PATH 問題。

対処:
- dotnet --info で SDK 状態を確認する。
- 必要なら .NET 8 SDK をインストールする。

## 9. セキュリティ運用上の注意

- credentials.json と OAuth シークレットを含むファイルは公開リポジトリへコミットしない。
- EmbeddedGoogleOAuth.cs は機密情報を含むため、取り扱いに注意する。
- 必要に応じて、配布用ブランチではシークレットを再発行して運用する。
